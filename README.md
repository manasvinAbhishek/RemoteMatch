# RemoteMatch — v0.2 first look

An accessible, responsive **frontend prototype** for a career-intelligence platform focused on worldwide remote jobs open to candidates in India.

## Preview
Open `index.html` in a browser or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Included in this demo
- Overview dashboard
- Sample job matches (explicitly illustrative, **not live verified**)
- Resume/job-description keyword coverage (not AI generation)
- Editable skill self-ratings and one foundation quiz
- 10/100/1000 monthly-credit **simulator** and bonus-credit simulator
- Mobile-responsive design

## Not implemented yet
Live job collection, candidate accounts, PDF/DOCX parsing, AI resume generation, verified assessments, secure credit ledger, application tracking, subscriptions, and production data privacy controls.

## Product principles
Free users can discover jobs, create 10 tailored resumes/month when backend generation is implemented, review skill gaps and complete basic assessments. Higher tiers scale to 100 and 1000/month. Additional credits can be earned from validated assessments. Never invent experience or imply a universal ATS score.

## Next milestones
1. Authenticated API and database.
2. Resume parsing and factual AI tailoring.
3. India-eligible job ingestion with source verification.
4. Skill Passport and multi-level assessments.
5. Server-side monthly credit and bonus ledger.
6. End-to-end tests, security and deployment.

Do not upload private resumes to a public repository.
